## Contributing to the brainery

The contribution guide moved to [memo.d.foundation/contribute-to-memo](https://memo.d.foundation/contribute-to-memo).

It covers the branch and pull request path for staff with write access, the fork path for everyone else, and the guest writer path for outside authors. It also lists the lint errors you will meet and a checklist to run before you open a pull request.
