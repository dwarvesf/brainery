## The finding

In the Vô Vi / 9T prototype thread, bievh framed each martial manual as its own skill tree, not just a label on top of the same stats. Changing a manual means changing the tree; reaching a new realm can upgrade the manual, replace it with a higher-tier version, or add new skills. Factions and professions add another layer: different base sects can carry different passive skills, while side paths such as talismans or formations widen build variety.

## Why it matters to us

For a small prototype, this is a useful way to keep progression legible without flattening it into higher damage numbers. A player can understand the loop as a series of build decisions: choose a sect, learn or replace a manual, reach a new realm, then decide whether to specialize through professions, pets, wings, or secret-realm rewards. That gives the team more surfaces to test before the map is large. It also makes scope easier to stage: bievh noted that only one faction exists now, with at least three more planned, and that much of the system is planned but not implemented yet.

## Take it further

- Prototype one complete path before adding factions: one sect, one manual upgrade, one realm unlock, one profession modifier.
- Track whether each progression layer changes play, or only adds a stat bonus. If it does not change a player decision, cut or merge it.
- Use the browser-playable build as a test harness for input feel. Vincent noted the current combat is parry-driven and mobile support is still pending.
- Treat trailer generation separately from mechanics validation. The thread raised Hyperframes for promo footage, but gameplay clarity should come from the playable loop first.
